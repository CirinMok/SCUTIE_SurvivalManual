## 3.1 IE 是什么：入门必读

### 先欢迎一下

首先，欢迎来到工业工程 IE 的大家庭！

你可能因为各种各样的原因脱离了原来的专业，对新的专业抱着新的期待。所以下面这篇文档，可以给你大概交流一下**老登の经验**。

在大三放弃原专业的学习与积累，是需要莫大勇气的。IE 希望你能保持这股心气，多去提问、多去尝试，给大学剩下两年交出一份满意的答卷。

### 那么，IE 到底是什么

> **IE 是围绕生产现场展开的一系列提升效能的综合整治办法。**

说得再直白一点：别人关心"这个东西能不能造出来"，IE 关心"这个东西怎么造得又便宜又快又好又不容易出错"。

### 一个判断：工业工程适合什么样的人

如果要我回答，我会说：**是有勇气为自己决策负责的人。**

从结果看，工业工程让一些人却步的一个重要原因，是他看到 IE 拿的是管理学学位，就放弃了。

也确实是这样。来到工业工程的人，大多对自己的未来有个想法，只是在原专业的阻力太大，于是转到 IE 来。

换句话说：

- **工业工程适合已经有明确目标规划的人。**
- 如果你属于"按部就班完成任务"型，那传统工科可能确实更适合你——按部就班完成工作，拿一份稳定的薪水，没什么不好。
- 但来到工业工程，你要面对的是**广泛的知识**，和许许多多需要重新学习的内容。

### 但也正因如此

我认为工业工程更多的是给了你**一个机会**：一个成为你理想中自我的机会。

在这里你可以尽情地成为你理想的自己：

- 你可以在**运筹学**里重新理解线性代数
- 可以在**人因工程**里学会 CAD
- 可以在**数据分析**里学习数学建模
- 可以在**系统仿真**里用代码复现整个工厂的运作

**没有人能阻止你成为你自己。**

在原专业，你可能有数不清的实验，学着没有意义的知识，过着枯燥的人生。但来到 IE，周围的同学们都是**不安分于平庸的人**，你会重新锚定你的人生——

**你究竟想好要怎么过了吗？**

如果决定了，那就去做吧。

## 3.2 失败的思维

### 一个问题

市场上大多数工作，经过 3 年以内的培训，每个人都能适应。

那么问题来了：

> **为什么还有能力高低之分？**

如果技能是可以在三年内学会的，那三年后所有人都该一样强才对。但现实不是这样。有人三年做到主管，有人三年还在做同样的事。

**差距不在技能，在思维。**

技能是"会做什么"，思维是"遇到没做过的事怎么办"。前者会被培训和 AI 抹平，后者不会。

### 态度比结果重要

从小到大，应试教育告诉我们一句话：

> **过程不重要，只看结果。**

这句话在"有标准答案"的场景下是对的。做一道题，答案对了就是对了，你心里怎么想的没人关心。这是完成任务最高效的思维。

**但大学之后，标准答案就消失了。**

- 该选哪个方向？没有标准答案
- 这份实习要不要去？没有标准答案
- 这段关系要不要继续？没有标准答案
- 这个项目该不该投入三个月？没有标准答案

当你需要**自己去寻找答案**的时候，规则就变了：

> **这时，态度比结果重要。**

因为结果你控制不了。市场会变、政策会变、运气有好有坏。但你面对一件事的态度，是你能控制的。

### 什么事应该做

既然结果不可控，那判断标准是什么？

**三个问题，依次问自己：**

**1. 有没有"无论如何都值得"的理由？**

这件事本身有价值吗？哪怕最后失败了，我在过程中得到的东西值不值？

比如去实习：哪怕公司最后没给 return offer，你至少见了职场、写了代码、认识了几个人。这就是"无论如何都值得"。

**2. 有没有"失败后也能接受"的安排？**

最坏的结果是什么？我能承受吗？

如果最坏的结果是"浪费一个暑假"，那可以试。如果最坏的结果是"挂科退学"，那要慎重。

**3. 有没有设计逐步提高的成本，和失败后退出的计划？**

这是最关键的一条，也是最容易被忽略的：

**不要一次性 all in，要设计成"投入逐步加码、随时可以退出"的结构。**

- 想创业？先做一个小程序测水，别一上来就注册公司租办公室
- 想做自媒体？先发 10 条内容看看，别一上来就辞职
- 想转方向？先修一门课、做一个项目，别一上来就放弃现在的专业

**让你的失败，建立在为他人探索的试错路径上。**

这句话很狠。它的意思是：你的每一次尝试，就算失败了，也是在给后来的人探路。你的失败不是浪费，是**数据**。

**然后，无论成败如何，接受代价。**

### 接受失败是常态

大学里我们被训练成"不能出错"。考砸一场、挂一门课、投简历被拒十次，就觉得自己完了。

但真实世界是这样的：

- 一个 IE 项目做出来，第一版方案被否掉，是**正常的**
- 投 50 份简历，只拿到 3 个面试，是**正常的**
- 一个模型跑出来结果和实际差很远，是**正常的**

**失败不是意外，失败是流程的一部分。**

真正的失败只有一种：**因为怕失败，所以没开始。**

## 3.3 二八定律

> **用 20% 的时间，学会 80% 的内容。**

这不是偷懒，这是**资源分配**。

一门课有 500 页教材，但考试考的是其中 100 页的核心概念。一份工作要求 10 项技能，但真正决定你能不能留下的，是其中 2 项。

IE 的思维方式本来就是"找瓶颈、抓关键"。把这个思维用在自己身上：

- **识别那 20%**：哪部分内容反复出现？哪个技能是岗位硬要求？
- **集中火力**：把那 20% 做到 90 分
- **剩下 80%**：做到 60 分及格就行，别追求完美

**完美主义是效率的敌人。**

一门课从 90 分提到 95 分，可能要花掉你两倍的时间。这两倍时间，够你把另一门课从 40 分提到 80 分。

### 量化你的精力和时间

这是本手册里最重要的一条建议：

> **要么有趣，要么有用，要么睡觉。**

把每一个小时扔进这三个桶里的一个：

| 桶 | 判断标准 |
|---|---|
| **有趣** | 让我开心、放松、恢复能量 |
| **有用** | 推进我的目标（学业、实习、技能、关系） |
| **睡觉** | 恢复精力，为前两项提供燃料 |

**三个桶之外的，砍掉。**

- 刷两小时短视频，既无趣（刷完只觉得空虚），又无用，还占用了睡觉时间 → **砍掉**
- 参加一个不感兴趣也无意义的社团会议 → **砍掉**
- 为了合群陪聊到凌晨 → **砍掉**

反过来，有些事看起来"没用"——比如和学长吃一顿两小时的饭，或者看一本跟专业无关的书——但它可能属于"有用"或"有趣"，**那就值得**。

**关键不是忙不忙，是每小时扔进了哪个桶。**

### 两张表：现金流量表与损益表

还有一层更深的判断标准。

> **一张是当下的现金流量表，一张是长期的损益表。**

- **现金流量表**：这个月我进账多少、支出多少。对应到学生时代，就是这学期绩点多少、拿到了什么、马上能变现什么。
- **损益表**：长期看，我是亏的还是赚的。对应到长期，就是我的**能力、认知、人脉、健康**是在增值还是在折旧。

绝大多数人只盯着第一张表。绩点高就开心，实习没找到就焦虑——这些都是现金流量表的波动。

但真正决定你走多远的，是第二张表：

> **你能否在本职工作之余，挤出时间做个人成长性的学习。**

这句话是判断一个人天花板的硬指标。

- 有人下班后刷短视频到凌晨——损益表在流血
- 有人下班后学一门新技能、读一本书、写一点东西——哪怕每天只有半小时——损益表在增值

**短期看差距不明显，五年后是两类人。**

所以，不要只问"这件事现在给我带来了什么"，还要问：

> **这件事，是在给我的长期损益表做加法，还是减法？**

## 3.4 务实的行动

### 从"想清楚"到"开始做"

很多人卡在第一步：想不清楚，所以不动。

但现实是：**你不可能在岸上想清楚怎么游泳。**

正确的顺序是：

```
做一个小动作 → 观察结果 → 调整 → 再做
```

而不是：

```
想清楚全部 → 完美执行 → 一次成功
```

**先做一个能做的版本，再迭代。**

- 不知道要不要学 Python？装个环境，跑通一行 `print("hello")`
- 不知道要不要考研？买本数学书，做两章题
- 不知道要不要走数据分析？打开一个公开数据集，用 Excel 画个图

**行动本身会给你答案，思考不会。**

### 关于"华工很务实"

关于这两个字，我在第一章已经写了一整节。

这里只补一句：

**务实，本身就是一种行动哲学。**

它不浪漫，不好看，不适合发朋友圈。但它管用。

当你不知道该选哪条路的时候，选**那条能立刻开始做的**。

### 给还没决定的你

如果你正在犹豫要不要转到工业工程，我只说一件事：

**这不是一个"更轻松"的选择。**

IE 的课程横跨管理、数学、仿真、经济，你需要学的东西比单一工科更多。它的好处不是省力，而是**给你更大的自由度**——你可以往数据走、往供应链走、往咨询走、往制造业走。

自由是有代价的，代价就是**你要自己选**。
