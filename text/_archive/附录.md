# 附录 A 搜索方法论

> 信息时代最大的能力差距，不是智商，是**会不会找**。

## A.1 搜索的本质

**信息收集三原则：**

1. **多维度、尽量宽泛**——不要一开始就收窄
2. **当重复内容达到 50%，停止**——再搜下去是浪费时间
3. **信息为结论服务**——先想清楚"我要证明什么"，再去找证据

## A.2 关键词设计

**第一步：从目的倒推关键词**

```
目的 → 领域背景 + 主体 + 行为 → 关键词框架
```

**第二步：学会用搜索语法**

| 语法 | 作用 | 示例 |
|---|---|---|
| `AND` / 空格 | 与 | `工业工程 就业` |
| `OR` | 或 | `供应链 OR 物流` |
| `-` | 非 | `IE -国际` |
| `"…"` | 精确短语 | `"生产计划与控制"` |
| `site:` | 限定站点 | `site:zhihu.com` |
| `filetype:` | 限定文件类型 | `filetype:pdf` |
| `intitle:` | 限定标题 | `intitle:运筹学` |
| `inurl:` | 限定网址 | `inurl:report` |

> 提示：中文搜索用**半角**符号效果更好。

**第三步：换同义词**

从第一步学到的术语出发，去找**衍生词、全称与缩写、中英文对照**。

## A.3 找信息源

**通用入口：**

- **虫部落**系列（搜索、学术、电子书聚合）
- **AnywhereAnything**：跨站搜索导航
- **similarsites**：查找相似网站

**按平台类型：**

| 类型 | 平台 |
|---|---|
| 社区问答 | 知乎、Quora、贴吧、豆瓣 |
| 视频 | B 站、抖音、YouTube、快手 |
| 技术 | CSDN、GitHub、Stack Overflow |
| 财经 | 雪球、脉脉 |
| 消费 | 小红书、得物、什么值得买 |

**换三个维度再搜一次：语言 / 时间 / 关键词。**

## A.4 信息对比与验证

**批判性思维找证据：**

1. **线上原文 vs 线下访谈**——一手信息优先
2. **找最早出处**——`original`
3. **交叉验证**：同一件事，不同立场的人都怎么说？

**信源等级（从高到低）：**

```
期刊 > 学位论文 > 会议论文 > arXiv 预印本
官方文件 > 一手访谈 > 行业研报 > 二手转述
```

**常用权威源：**

- 国家哲学社会科学文献中心（ncpssd.org）
- 中国统计数据库（stats.gov.cn）
- Our World in Data
- 得到 / Open Library（书籍）

## A.5 找数据

**宏观数据：**

- 国家统计局
- 国家数据（data.stats.gov.cn）
- 北大数据开放平台

**微观 / 商业数据：**

- 大数据导航（hao.199it.com）
- 参照系、天天投、投中网（行业公司列表）
- CB Insights（独角兽）

**付费专业数据：** 彭博、路透、S&P、Wind

## A.6 数据欺骗：怎么识破

**六个必查项：**

1. **真实性 / 时效性**——数据是哪年的？
2. **是否隐瞒了信息**——省略规模只谈百分比？
3. **数据与结论是否对齐**——先自己从数据推结论，再对比作者结论
4. **平均值是什么**——平均数？中位数？众数？分布如何？
5. **测量误差**——怎么测的？
6. **图表是否被拉长压缩**——看刻度起点

## A.7 按场景搜索

### 搜行业 / 产业

1. **知识框架**：行业图谱、Market Map、行研报告 → 理清上中下游
2. **公司与个人**：上市公司财报（巨潮、Wind）；非上市公司融资历史
3. **证据**：Crunchbase、Dealroom；行业展会、客户痛点

### 搜公司（"扒裤衩"四步）

1. **全国企业信用信息公示系统**（gsxt.gov.cn）——注册资料、法人、经营状态、社保缴纳人数、失信、行政处罚
2. **中国裁判文书网**（wenshu.court.gov.cn）——劳务诉讼、欠薪、非法裁员
3. **中国执行信息公开网**（zxgk.court.gov.cn）——法人是否为老赖
4. **搜索年报** + `公司名 关键词` 找负面新闻

> 相信网络上的吐槽——**负面情绪才是事实**。
> 再补充：招聘信息、展会、近期合作合同。

### 搜人

| 目标 | 方法 |
|---|---|
| 基本信息 | 单位官网、工商登记、国家征信 |
| 人品 | 各平台社交媒体、问其同学同事 |
| 导师 | 知网/WoS 搜名字；看二作是否在录取名单；看二作论文致谢；查国自然基金；贴吧搜缩写；问师兄师姐延毕比例 |

### 搜学术

- 中文：知网、维普、万方、中科院 PubScholar、百度学术
- 英文：Web of Science、Google Scholar、arXiv
- 电子书：鸠摩搜书、Anna's Archive、OpenStax（外文教材）

> ⚠️ 提醒：本文提到的部分站点（文献镜像、电子书站）**稳定性差**，可能随时失效。请以**学校图书馆已购数据库**为第一优先。

### 搜资源

- **图片**：Google 以图搜图、Pexels、Pixabay
- **PPT**：各类模板站、Canva
- **英语真题**：各类真题站

# 附录 B 批判性思维：常见谬误清单

> 这一节教你**怎么不被忽悠**。
> 用处：看营销号、读研报、听讲座、甚至和同学辩论的时候。

## B.1 提问检视表

看任何一段论证，问三个层次的问题：

**一、是否浪费脑力？**
- 这个话题讨论的情景是什么？目的是什么？
- 对我来说重要吗？

**二、结构**
- 结论是什么？论题是什么？
- 前提和理由是什么？论证推理过程是什么？

**三、细节**
- 论题和结论是否对齐？
- 结论的倾向、局限是什么？有没有绝对化、二分？

## B.2 论题：事实 vs 价值

- **事实性论题**：世界**是**什么样
- **价值性论题**：世界**应该**怎么样

> **警惕"应该"思维的滥用。**
> 很多事情你无法控制，把"应该"改成"希望"，心态会好很多。

## B.3 结论相关谬误

| 谬误 | 含义 |
|---|---|
| **稻草人** | 歪曲对方观点，然后攻击这个被歪曲的观点 |
| **人身攻击** | 攻击人，而不是反驳其理由 |
| **乱扣帽子** | 因为给某事起了个名字，就以为解释了它 |
| **转移话题** | 插入不相干话题，转移注意力 |
| **诉诸情感** | 用恐惧、希望、怜悯等情感代替论证 |

**破除方法：站在三个立场上重新看**
1. 作者/发言者的立场
2. 反对者的立场
3. 不同情景下的立场

**追问四个维度：**

- **信念**：来自生物本能？个人经验？社会共识？信仰？——不要去攻击信念，试着让对方接受推理过程
- **立场**：你的身份是什么？利益从哪来？换个立场还成立吗？
- **欲望**：我想得到什么？别人想要什么？得到了还会有这个想法吗？
- **情绪**：我的情绪如何？相反情绪的人会怎么看？

## B.4 选择谬误

- **二分法**：明明有多个选项，却假想只有两个
- **追求完美**：因为方案不能解决所有问题，就认为它完全不可取

**破除**：给结论加上限定条件——"在什么条件下，这个结论是成立的？"

## B.5 论据相关谬误

| 谬误 | 含义 |
|---|---|
| **以偏概全** | 用有限的样本得出整体结论 |
| **诉诸权威** | 引用权威，但该权威对此论题无专门知识 |
| **诉诸公众** | 因为很多人都这么说，就认为有道理 |

**论据来源类型**：典型案例、权威意见、个人经历、当事人证言——**各有局限，都要交叉验证**。

**调查问卷四查：** 抽样能否代表整体？样本够大吗？覆盖够广吗？随机性够吗？

## B.6 数据相关谬误

- 数据来源不明
- 研究未被重复验证
- 适用范围过时
- 通过省略数据欺骗（只谈百分比，不谈规模）
- 数据结论 ≠ 需要证明的结论
- 平均值含糊（平均数/中位数/众数）
- 图表故意拉长缩小

## B.7 因果相关谬误

| 谬误 | 含义 |
|---|---|
| **过度简化因果** | 用不足以解释全局的单一因素解释事件 |
| **忽略共同原因** | 两件事相关，其实是第三个因素导致 |
| **事后归因** | 仅仅因为 B 在 A 之后发生，就认为 A 导致 B |
| **基本归因错误** | 解释他人行为时高估个人因素、低估环境因素 |

**寻找替代原因的标准：**

- 在预测类似事件上的成功率
- 有多少已接受的事实支持它
- 有多少已接受的信念不支持它
- 它能解释多少种不同类型的事实

## B.8 论证结构相关谬误

- **滑坡谬误**：假设 A 会引发一连串不可控后果，而实际上有现成程序可以阻止
- **循环论证**：用结论本身（换个措辞）作为理由
- **因果混淆**：把"解释已知现象"和"论证未知观点"搞混

## B.9 推理的两条路

| 类型 | 方向 | 特点 |
|---|---|---|
| **演绎** | 一般 → 特殊 | 前提为真则结论必真 |
| **归纳** | 特殊 → 一般 | 结论是概率性的 |

# 附录 C 学科知识地图

> 这一节不是要你学完。
>
> 它的作用是：**当你想学某个东西的时候，知道它大概在哪、旁边有什么、该从哪进。**
>
> 一张地图的价值不在于走遍，而在于**知道自己要去哪、现在在哪**。

## C.1 为什么要看这张图

大学最大的问题不是"学不会"，是**"不知道自己不知道"**。

你不知道有个领域叫"因果推断"，就不会去搜它；
你不知道运筹学下面还有"数值优化"，就会以为运筹学只到单纯形法为止。

**这张图的作用，是在你脑子里点亮一个个"我知道有这么个东西存在"的神经元。**

## C.5 怎么用这张图

**不建议**：从上到下把每一块都学一遍。你会死在第二块。

**建议**：

1. **先锚定一个方向**（比如"数据分析"）
2. **沿着这一条线深入**（统计 → 因果推断 → 机器学习 → 业务落地）
3. **旁边的领域，知道存在就行**，需要的时候再回来查

> 广度给你视野，深度给你饭碗。
> **先有深度，再扩广度。** 反过来的人，四年后什么都懂一点，什么都不精。
