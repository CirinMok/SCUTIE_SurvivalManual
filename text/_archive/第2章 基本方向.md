## 2.0 先认识一下这个专业

工业工程（Industrial Engineering，简称 IE）在华南理工大学隶属**工商管理学院**——注意，不是机械学院。

这一点非常重要，因为它直接决定了你的学生证上写的是"管理学学士"，以及你未来投简历时，HR 对你第一眼的理解。工业工程在国内的归属挺分裂：清华、上交、重大、浙大把它放在机械学院；天大、西交、华工把它放在管理学院。**没有对错，只是研究侧重不同。**

一句话概括 IE：

> **IE 是围绕生产现场，展开的一系列提升效能的综合整治办法。**

听起来很糙，但这就是本质。别人造飞机，你负责让造飞机的过程更省、更快、更不出错。

### 我们的课，大概分三类

**第一类：管理与数学**（理论根基）

- 运筹学
- 管理统计学
- 数据库与数据系统
- 预测与决策方法
- 管理学原理、管理信息系统
- 生产计划与控制 / 运营管理、服务运作管理
- 质量管理、供应链管理、物流管理、库存管理

**第二类：仿真模拟与机械**（具体工具）

- 系统仿真
- 人因工程学
- 基础工业工程、设施规划与物流系统、产品开发

**第三类：经济与技术**（应用方向）

- 微观经济学
- 技术经济学

**如果只准备考研**：最重要的是大三上的**运筹学**和大三下的**管理统计学**。这两门是核心中的核心，其余都是延伸。

**如果你想在就业市场更有竞争力**：建议加修一两门涉及机器学习、数据分析的课。学院里值得关注的：

- 唐四慧老师《商业数据分析》
- 沈子凡老师《商业决策》
- 朱文斌老师《大数据挖掘》

> 这三门课的价值在于，它们能让你从"会算运筹模型的 IE 学生"变成"会用数据解决业务问题的人"。后者的市场溢价高一个量级。

## 2.1 升学

### 考研

**关键政策变化：27 届之后，MEM（工程管理硕士）对应项目要求工作经验。**

这意味着什么？意味着传统的"应届生考 MEM"通道基本关闭了，应届生主流的选择变成**管理科学与工程**等学术型或非工程管理类的专业。

所以你要做的第一件事是：**去查目标院校目标专业的最新招生简章**，看清楚它今年招什么、考什么、要不要工作经验。不要用三年前的经验帖去规划今天的考研。

**备考提醒**：

- 运筹学是很多学校管理科学与工程专业的专业课科目，也是你的强项
- 数学是分水岭，早点启动
- 择校时优先看**报录比**，不要只看学校名气

### 保研

基本就别想了。比例太低。

这话我说得很直白，因为不直白会害人。工业工程在华工管院的保研名额极少，大部分同学不要把它当作主路径来规划。**知道它存在，但如果你的绩点不在年级前几名，请把精力放在其他选项上。**

### 出国

唐四慧老师**强烈建议出国深造**，而且偶尔会邀请留学回来的学长学姐做经验分享。这是一个值得认真对待的信号——一个了解行业的老师说"建议出国"， обычно基于她看到的就业市场和学术路径的真实差距。

另外，强烈推荐看[《上海交通大学学生生存手册》](https://github.com/SurviveSJTU/SurviveSJTUManual)里关于出国的部分，写得很扎实。

如果你是 IE 想出国，方向大致有：

- **Industrial Engineering / Operations Research**：最对口
- **Business Analytics / Data Science**：就业导向强，近年热门
- **Supply Chain Management**：偏管理，申请门槛相对友好

### 考公 / 选调

这条路信息密度极低，坑极多，所以我把工具都列出来：

**官方信息源（优先级最高）**

- **广东省人力资源和社会保障厅**：本省岗位、政策原文
- **国家人力资源和社会保障部**：国家级政策、全国岗位

**定向选调**

华工作为 985，是有定向选调资格的。定向选调的竞争烈度通常低于普通国考省考，是体制内的一条相对友好的路径——但名额有限，需要提前研究目标省份的公告。

**信息聚合工具**

- 粉笔公考雷达（岗位筛选、报名提醒）
- 国聘行动（国企岗位）
- 国资小新（国资委官方账号，国企招聘信息）

> ⚠️ 提醒：公考信息里营销号噪音极大。"某岗位报录比 1000:1"这类标题99%是贩卖焦虑。**只信官方公告**。

## 2.2 就业

### 基本情况

IE 的就业方向这些年有明显变化：

| 时期 | 主流去向 |
|---|---|
| 2020 年以前 | 互联网企业（运营、产品、数据、供应链） |
| 2020 年以后 | 新能源制造业（宁德时代、比亚迪、小鹏、广汽等） |

**一个好消息：你投岗位不会被筛简历。**

这是学长学姐的原话，含义是——IE 的"管理学学位 + 工科背景"组合，在简历筛选环节是比较通吃的。你能投互联网的运营/数据岗，也能投制造业的 IE/供应链/生产计划岗，还能投咨询、物流、零售。

**但要清醒一点**："不被筛简历"意味着"更容易进入下一轮竞争"，不意味着"更容易拿到 offer"。简历过了之后，比的是真本事。

### 学长学姐都去哪儿了

从管院学长的分享材料里，可以看到 IE 出身做数据分析类岗位的实际路径：

```
滴滴出行（运营策略分析）
    ↓
携程（酒店定价）
    ↓
字节跳动（产品分析）
    ↓
腾讯（商业化分析）
```

**这条路径的核心能力，不是运筹学，而是"用数据回答业务问题"的能力。**

所以如果你想走这条路：

1. **SQL 是必修项**。不管教材上教不教，自己学。
2. **Python 是加分项**。庄东老师的运筹学课会带你快速入门，别浪费。
3. **Excel 是基本功**。别笑，真的。
4. **统计学要给够时间**。假设检验、AB 实验、因果推断——这些是数据分析岗的面试高频。

### IE 到底能解决什么问题

这里直接引用学长的分享框架，从简单到复杂，五个层次：

**1. 单一系统的优化——电梯午高峰排队**

只有一种实体（人）、一种资源（电梯）。用仿真 + 优化，把午高峰的电梯方案改一改：

| 指标 | 现有 | 优化后 | 变化 |
|---|---|---|---|
| Cycle Time | 14.0 min | 2.4 min | **-83%** |
| 平均排队时间 | 11.8 min | 1.4 min | **-89%** |
| 最长排队长 | 85 人 | 41 人 | -52% |
| 吞吐量 | 26.5 人/min | 37.9 人/min | **+43%** |

核心思路一句话：`Cycle Time = 有效 CT + 无效 CT`，把无效停留砍掉，整体效率就上来了。

> 这就是 IE 的味道——不需要发明新电梯，只需要重新安排停靠逻辑。

**2. 多系统的优化——仓库效率**

从订单流入到包裹出库，涉及多个环节、多种实体、多种资源。问题变成：如何最大化整个仓库系统的效率？

**3. 复杂系统的优化——供应链网络（仓 + 网）**

需求侧做聚合，供给侧考虑节点、网络、产能、成本、时间。目标函数：`min 总成本`。

**4. 大型综合系统的优化——企业决策系统 / 电商人货场**

**5. 未来：DA / DS / BA 的终局**

这里有一个特别重要的视角，来自学长的分享：

> 分析师的终局是什么？

这个问题没有标准答案，但方向大致是：**从"做报表的人"变成"定义问题的人"**。技术会过时，但"能不能把一个模糊的业务问题，翻译成一个可以计算的问题"——这个能力，AI 短期内替代不了。

### IE vs AI：会被替代吗

学长给的答案很清晰，三个方向：

**1. 跨界设计：多领域融合**

IE 融合经济、心理、技术等多领域知识。比如智能交通系统，要同时懂交通工程、心理学、信息技术。AI 擅长单点，不擅长跨界的"缝合"。

**2. 人性化平衡：效率与体验兼顾**

IE 天然的基因是"在算法效率和用户体验之间找平衡"——因为 IE 本来就是研究"人-机-系统"的。比如电商推荐系统，纯算法会把人困在信息茧房里，而 IE 会问：推荐效果和用户满意度怎么同时优化？

**3. 人机指挥家：AI 与人类协作**

IE 工程师的角色是"人机指挥家"——让 AI 处理数据，人类负责决策。

所以：

> **不会用 DS 的数据分析师，不是好的数据分析师。**

打不过就加入。与其焦虑 AI 会不会取代你，不如想想怎么让 AI 成为你的实习生。

## 2.3 实习

**基本方向**：

- **互联网**：数据分析、商业分析、产品、运营、供应链
- **制造业**：工业工程师、生产计划、精益改善、供应链、质量

## 2.4 学业课业

这一节是全手册最实在的部分。以下每条经验都来自历届 IE 学长学姐的真实留言。

### 先说一件事：学神为什么不听课

你一定见过这种人：课上在打游戏、写别的作业、甚至不来，最后考得比你高。

别急着说人家天赋好。拆开看，无非三个原因：

**1. 天生的缓冲更大**

记忆容量大、处理速度快。别人要两小时才能消化的东西，他半小时就够。这是硬件差异，你改不了，也不用纠结。

**2. 他已经有前置知识了**

这是最容易被忽略的一条。所谓"学神"，很大概率**在别人还没开始的时候，就已经预习过了**。

新知识不是孤立地进入大脑的，它要挂在你已有的概念网络上。一个已经搭好框架的人，老师讲到第三个公式，他脑子里已经在想第五个公式了。而一个零基础的人，光是把第一个定义听懂，就耗光了注意力。

**3. 他听完预习后，会精准地听**

有框架之后，他不会平均用力。他只在**自己不懂的地方**集中注意力，剩下的时间大脑处于低功耗待机。

**所以这三者的结论是什么？**

> **考试培养的是专注能力，平时上课培养的是"挤时间摸鱼"的能力。**

这句话有点绕，但很重要：

- 考试场景下，你要能在一段时间内**高浓度聚焦**
- 而大学真正的自由，是在课业之外**自己挤出时间学东西**
- 学神的优势，从来不是"上课更认真"，而是**早就把框架搭好了，所以上课可以不用那么用力**

**给你的启发**：

- 如果你不是原因 1 那种人（大概率不是），那就去补原因 2：**提前预习，哪怕只是扫一遍目录和概念**
- 一次预习的投入，能换来整门课上课效率的成倍提升
- 不要用"我不听课"来模仿学神。你模仿的是他玩手机的动作，不是他之前一个月的准备

### 📌 运筹学

**核心中的核心。**

如果你们是**庄东老师**教的话，那么恭喜你们，你们遇到了一个特别好的老师。

庄老师的课有个特点：作业通过他自己开发的网站提交，**按提交时间给分**。你会感觉很累，但你也会第一时间就想把作业做完——这大概就是设计者的意图（笑）。

**怎么学**：

- 跟着老师好好学就没问题。期末他会放出刷题材料，搞懂、做会、练熟，考高分分分钟的事。
- 有学长 96 分排班上第八名——所以你懂的，这门课大家都考得好，不能掉以轻心。
- **上手有点难**，因为线性代数的知识大概率已经忘光了，需要重新理解。
- 那个 OJ 平台非常有利于学习，一定要好好用。
- 需要帮助可以找学长学姐要笔记。
- 入门推荐视频：《线性规划的艺术》

**附带福利**：庄哥会带大家入门 Python。说是"带大家入门"不太准确，应该说是**逼大家快速自学入门**（2333）。过程可能有点辛苦，但对将来想走数据分析方向的人，是一个特别好的开端。

**23 级补充**：随着 AI 的发展，课本上许多题目和代码可以靠 AI 解决，但这并不意味着我们学的东西没用。运筹的核心是**以目标为导向，综合运用各种决策方案，逐步根据约束优化到最优解**——这个思想方法才是真正有价值的。

> **如果说 IE 最核心的课程，是运筹学、统计学、数据库、预测决策、生产计划与微观经济学。而核心中的核心，就是运筹和统计。**

### 📌 数据库

**emmmmm……唐老师讲课讲得很不清晰，希望你们不是她教（233）。**

我们这门课**完全靠自学**（hhh）。其实东西不难，而且有上机课练习，不懂就课下多看课本然后动手练。

- 清华那本教材说实话也不怎么样，可以尝试找找别的教材。
- **考试题型**：单选、填空、简答（写代码）、综合题
- 相关题目可以网上找，**可能考到你刷的原题**——我们那年最后一道大题考了图书馆那个。
- **代码一定要自己动手写，光看懂是没用的。**
- SQL Server 2005 安装估计会出现各种问题……如果登录不上，记得"以管理员身份运行"。
- 也可以装 2017，不过 2008 之后 `compute by` 语句就不支持了。

**23 级补充**：

唐老师人挺好，但讲课想一出是一出。

不深入学习的话，数据库不算难。数据库的核心是**表**，用各种表来存储数据，考试考察的就是对这些表的定义、操作、理解，比较简单，基本都有 90 分。

数据库是很多后续内容的思想基础，学了对生活帮助很大（真的，不骗你）。但**不建议装 SQL Server 本地环境**——想干开发的话，对语法有个了解就行，然后直接上手现代后端开发项目。

### 📌 微观经济学

这门课内容有点多，不过其实都不难理解，老师也比较好。课上听不懂，课下多看看书总会看懂的。

- 不用纠结第六版还是第七版，都一样，只是习题部分有点不同。
- **题型改版了**：原来只有简答和案例分析，现在多了单选，但单选比重不高。题型老师会在考前说明。
- 这是**管院精品课程，没有历年试题流出**。但是和管院大一新生**统考**，所以为了照顾大一新生，题目不会出得太难。
- **大题会考好几道复习资料里的原题**（就是那份全是大题的复习资料）——务必刷。
- 案例分析要自己理解掌握知识往上套。我们那年考了"携程购买机票时默认勾选保险"的行为分析。
- 单选自己上网找题刷。

**23 级补充**：

这门课是 IE 为数不多和经济学有关的内容，数学推导比较少，有些概念可能不清晰——可以参考 B 站"原力总督"学习。

如果对经济学感兴趣，可以接着学经典四门：**马克思政治经济学、曼昆宏微观经济学、计量经济学**；再往后是金融学 431 的课程：国际金融、货币银行学、公司理财、投资学。

> 咱们 IE 就是把经济学的课程压缩进一门微观经济学，把金融学的课程压缩进一门技术经济学。

学这门课还有一个额外收获：**你可以用经济学的观点重新看待自己以前的专业**。你或许会对原来专业里那些不理解的现象，有一种恍然大悟的感觉。

### 📌 管理学原理

给我们上的是**王红丽老师**。

听学长说以前有个学长在课上跳小鸡恰恰舞，期末 +5 分——你们可以问问老师这届是否还能这样（：）。

管理学无论是思想还是教材，主要来源于西方，来到中国多少有些水土不服，或者说不接地气。

不过，这门课给了我们**除了运筹学之外的另一种思维方式**：

> 通过组织、激励、标准流程化来解决问题，而不是用各种算法优化。

**不要拿着运筹学学到的"优化"当锤子，看所有企业都像钉子。**

这里与其说是门课程，不如说是**了解班级里不同同学的机会**。未来能无所顾忌表达自己的地方会越来越少，希望在这里你们能凝聚成一个班级。

哈佛的管理学大多以案例为线索，鼓励小组讨论。王红丽老师虽然比较学术派，但在这门课上**十分鼓励不同的个人意见**。希望你可以多多发言，学术自由讨论。

### 📌 系统仿真

**这门课刚上手的时候很痛苦，但是上手之后就好啦。**

**教材问题**：学校没有订，需要自己拿电子版到外面打印，或者找师兄师姐借。老师会给电子版。这本教材在国外号称仿真界的圣经，可惜翻译只到第三版，而且第三版还绝版了——所以各位只能含泪看全英教材。

不过庆幸的是，第四版和第三版虽然有很多不同，但仍有不少地方能对上（比如第四章全部对得上），算是不幸中的万幸。

**学习建议**：

- 课后题目要好好做。看不懂就看中文版，但第四版更新了一些题目，有些在中译本里找不到。平时还是强迫自己习惯英文，**因为考试题目是全英的**。
- 这门课说是双语，但老师**上课全程英语**。你可以用中文问她问题，课下她会讲中文。
- 一开始会很难懂，但要强迫自己听懂。老师很好，不懂的地方问她，她会重新讲。
- **每堂课的前后关联很大**，一定要当堂解决问题，不要留拦路虎。第三章搞不懂，后面几章都是建立在前面的基础之上，前面不懂后面就崩盘。
- 只讲第三、四、五、九章。考试不考没讲过的。期末四道大题，如果平时作业都搞懂了完全没问题——无非是课本例题和课后题的变种。

**偷偷安利一个小妙招**：找个录屏软件，老师切屏演示的时候把演示录下来，课后不懂还能回顾。

> 手机录也行，只是很耗电、不清晰、文件还大，最重要的是手会酸会累（233）。录屏软件貌似不能录音，不过老师讲英文，估计和没声音也没差吧（233）。要把握好录屏时机，不然被切屏就不能操作了，最好在老师切屏前就开始录，切完就暂停。

**23 级补充**：

我们这门课是**吴永忠老师**上的。他有点 i（内向），需要你自己主动去问他问题，千万别不问自己想。

**课程核心是解决运筹学中排队论的问题**。由于数学解析解复杂且不符合实践，所以用 **ARENA** 进行仿真，主要研究：

1. 实体 Entity 的间隔到达时间
2. 资源 Resource 的处理时间
3. 从而计算出队列 Queue 的等待时间

在 ARENA 里，用 `Create → Process → Disposal` 三个模块就能做仿真，最后看报告、用 Plot 画图优化等待时间。

入门视频：https://www.bilibili.com/video/BV1vP41117Ss/

### 关于备份：这是一个 IE 学生该有的素养

作为一个工业工程学生，如果你连自己的数据都不做冗余备份，那这门专业你算是白学了。

**备份策略（3-2-1 原则）**：

- **3 份文件**
- **2 份备份**：一份在云端，一份在硬盘
- **1 份物理隔开**：放在不同物理位置

**执行节奏**：

| 频率 | 动作 | 工具 |
|---|---|---|
| 每日 | 快照同步 | 威联通 NAS + QSync |
| 每周 | 加密上云 | 百度云（加密后上传） |
| 每月 | 冷备份 | 移动硬盘 |

> **科教试剂工程落实**：如果你参与实验室工作，试剂的采购、登记、使用、废弃流程要按规范落实并留档。这是 IE 的"标准化"思维在实验室里的应用。
