# 第一章 认清现状

> 在改变世界之前，先搞清楚自己站在哪里。

> **来路无可眷恋，穷途唯有向前。**

---

## 1.1 前言：单晶管的自白

如果把大脑比作电脑的处理器，有的人天生是 5G，而我是一根单晶管。

我做不到在 2 小时的高强度计算里保证不出错。一场三个小时的考试，前一个半小时我是 5G，后一个半小时我是拨号上网——转圈，卡顿，掉线。我一度以为这是态度问题，后来发现这是物理问题。

**承认自己的极限，不是认输，是止损。**

高考这张卷子，回答不了"你是什么样的人"。它只能回答"你在那个六月的那两天，把六门课的内容能回忆起多少"。前者是终身课题，后者是一次性的记忆检索。用后者去定义前者，就像用体检报告里的一项指标去定义你的人生——

> 合理，但很蠢。

所以这本手册想做的事情很简单：我们这些先走一步的人，把踩过的坑、走过的捷径、以及那些"要是早知道就好了"的事，尽量诚实地说出来。

它可能有用，可能没用；可能让你会心一笑，也可能让你皱起眉头。我们都接受。

**唯一的目标：大学是人生中试错成本最低的一段时间。**

出了校门，试错的成本要用房租、KPI、职场口碑来支付。在校内，试错的成本可能只是一个学期的绩点、一次失败的小组作业、一段不长的尴尬。这个差价，就是大学送给你最贵的礼物。

请把它花掉，别存着。

## 1.2 大学到底给你什么

很多人对大学的理解还停留在"拿个文凭"。文凭当然重要，但如果你只带走了文凭，那你是花了四年学费买了一张纸。

大学实际给你的是三样东西：

### 一、学历证书 → 帮你拿到"技术活"的入场券

文凭的作用是**过筛**，不是**定级**。它决定了你能不能拿到面试机会，决定不了你面试完能拿多少。

所以别指望文凭替你干活。它是一张门票，进了场之后演出怎么样，看你自己。

### 二、平台资源 → 帮你学会"混社会"

这是大多数学生四年都没用起来的东西，也是这本手册最想强调的部分。

大学是一个**极低成本的资源池**：

- **国际交换 / 科研项目**：申请门槛远比你想的低，只是没人告诉你
- **大厂实习**：华工在珠三角的地理位置，是一个被严重低估的资产
- **家教 / 销售**：别小看这个。它会逼你面对大量陌生人群，训练你被拒绝 100 次还能笑出来的能力——这项能力在工作里比任何专业课都值钱

### 三、交朋友 / 谈恋爱 → 混进前辈和校友圈

大学里最值钱的资源，从来不是图书馆，是**人**。

一个已经毕业三年的学长，一句"我们部门在招人，我帮你内推"，可能比你三个月投简历都管用。而这段关系的起点，可能只是你在大三那年帮他搬了一次东西、端了一次茶、问了一个不那么聪明的问题。

**别怕姿态低。端茶拎包是入场券，不是终点。**

### 记住三个词：资源、经历、闭环

如果这一章你什么都记不住，就记住这三个词。

- **资源**：学校里有什么是你用得上的？老师、实验室、社团、校友、图书馆、数据库、企业合作。先知道有什么，才谈得上用。

- **经历**：你亲手做过什么？一门课的项目、一次竞赛、一段实习、一个小程序。**经历是简历上唯一无法被 AI 生成的资产。**

- **闭环**：你有没有把一件事从头做到尾？从定目标、找资源、动手做，到复盘迭代。大多数人只有"做过"，没有"做完"。

**资源 → 经历 → 闭环。** 这是一个飞轮。转起来一次，下一次会更容易；转不起来，资源永远是别人的，经历永远停在 PPT 上。

## 1.3 如何评价一所大学

所有大学都在宣传自己的排名、实验室、院士数量。这些东西跟你一个本科生，说实话，关系不大。

真正影响你这四年过得爽不爽、值不值的，是下面这六件事：

**1. 氛围是否自由、是否单一唯 GPA 论**

有的学校氛围宽松，允许你折腾副业、搞社团、逃一些没意义的课；有的学校疯狂考勤，早读点名、晚自习打卡、上课收手机，把你当成高三的延长版。

没有绝对的好坏——如果你是个需要外部约束才能学习的人，严格的管理反而是好事。但你要**知道自己在什么样的环境里**，而不是稀里糊涂被同化。

**2. 技术类社团是否丰富**

这是接触不同学科、不同人群最省力的渠道。在社团里，你遇到的可能是机械的、计算机的、设计的、材料的——这些人在未来会变成你的跨学科队友、创业伙伴、或者帮你内推的同事。

**3. 有没有讨论股票、就业、行业的群聊**

一个活跃的、讨论真实职业信息的群，价值超过十门导论课。它让你在大二就知道大四要面对什么。

**4. 校友圈是否联系紧密**

校友圈的密度，决定了你毕业十年后换个城市还能不能找到人一起吃顿饭。这是隐性的社会资本。

**5. 实习机会是否丰富**

**6. 城市圈**

这一条值得单独说。

> **华工最大的、被最严重低估的资产，就是它在广州。**
>
> 深圳一小时、东莞一小时、佛山半小时。你周围三小时车程内的制造业、物流业、互联网公司数量，超过国内绝大多数城市的总和。工业工程是一个高度依赖"现场"的学科，而你恰好站在全国最大的现场旁边。

## 1.4 学科难度 ≠ 产业发展

我们从小被教的是：做的题越难，考的分越高。

这个逻辑顺延到大学，就变成了一个想当然的推论：

> **我学的知识越难，我毕业拿的薪资就越高。**

**不是这样的。**

你想，什么样的行业，知识会特别复杂？

必然是**已经高度发展过、前人把该踩的坑都踩完了**的行业。它才会有那么多沉淀下来的知识、方法、定理、模型。

以前我们算一个极限要多难，有了微积分这个工具之后，许多问题迎刃而解。

所以规律是这样的：

> **一门学科的知识越复杂，越有那种让你拍案叫绝的证明，说明它发展越久、产业越老越成熟，就越难给出高薪。**

为什么？因为前人已经证明了某种模式就是最好用的，各种复杂情况都考虑到了。你要做的只是**把结论调包过来用**，不需要你创造什么。

反过来说：

> **一门学科的学习资料越少，说明它越前沿。很多知识还停留在论文里，没有沉淀进教科书。它给出的溢价就越高。**

**这条规律对 IE 意味着什么？**

IE 的课程体系横跨运筹学、统计学、管理学、经济学——这些都是**非常成熟、沉淀极深**的学科。线性规划的最优解理论发展了几十年，你今天在课本上学到的，是无数前人智慧的结晶。

好处是：**你不必从零开始发明，工具都是现成的。**

代价是：**光靠"会用这些成熟工具"，很难拿到高溢价。**

那溢价在哪里？

在**那些还没有沉淀进教科书的领域**——数据分析做了几年就开始换代的工具链、AI 落地的具体场景、你的行业 know-how 和判断力。

**所以结论不是"别学运筹学"，而是：**

- 课本知识要学扎实（这是你的地基）
- 但别指望课本知识直接变现
- 真正的溢价，来自**把成熟工具用在还没有标准答案的新问题上**

这也就是 IE 的尴尬和机会所在——它教你的是一套成熟的分析框架，而你要做的，是用这套框架去解那些**框架还没覆盖到的问题**。

> 你不需要发明微积分，但你需要知道，微积分解不了的那个问题，该用什么。

## 1.5 自我：以终为始

史蒂芬·柯维说的"以终为始"，翻译成大学生能听懂的话就是：

**先想清楚四年后你想站在哪里，再倒推今天该干什么。**

大部分人做选择的方式是"别人都在考，我也考"、"这个看起来比较稳"。结果就是四年后站在毕业季的岔路口，手里握着三个都不太想要的选项。

正确的做法是反过来：

### 第一步：定终点

你想要的是哪一种生活？

| 方向 | 关键词 | 代价 |
|---|---|---|
| 升学（考研/保研） | 学历提升、延缓就业、换赛道 | 一年高压备考，机会成本高 |
| 就业 | 早入场、攒经验、拿现金 | 起点学历可能受限 |
| 考公 / 选调 | 稳定、体制内、地域绑定 | 竞争激烈、收入天花板明确 |

注意：**这三条路不是互斥的，但不能同时全力准备。** 你必须在某个时间点做出取舍。

### 第二步：查信息

选方向之前，先把信息补齐。第二、三章会展开讲，这里只列清单：

- **升学**：考研考什么专业、报录比多少、专业课考哪几门；保研比例、绩点线、加分项
- **就业**：目标行业头部公司在招什么人、要求什么技能、什么时间开秋招/春招
- **体制内**：广东省人社厅、国家人社部、定向选调的政策文件原文（不是营销号解读）

### 第三步：倒排时间线

举个粗糙的例子：

```
目标：大四秋招进制造业/互联网做供应链或数据分析
├─ 大三上：运筹学、管理统计学拿到高绩点（专业课是硬通货）
├─ 大三下：找一个暑期实习（哪怕是中小公司，先有经历）
├─ 大三暑假：正式暑期实习，争取转正或拿到背书
├─ 大四上：秋招，投递 30+ 家
└─ 贯穿全程：学 SQL / Python / 数据分析工具，这是 IE 的通用货币
```

有了这张表，你每天该干什么就清晰了。**焦虑的反面不是躺平，是具体的行动。**

## 1.6 关于"华工很务实"这句话

进校之前，我经常听到别人评价华工，只有两个字：**务实**。

我当时很不理解。务实算什么评价？听起来像是"没有特色"的委婉说法。别的学校有"自由""浪漫""理想主义"，到我们这儿就两个字，"务实"。

后来我懂了。

务实不是一个宏大叙事，它是一件件小事。

我只讲两件事。

**第一件**，是我当时参加的一门网络通选课。当我带着一堆打印文件去教务处认学分，抱怨流程繁琐的时候，教务老师和我说：

> 其实学校这边能帮你们认的学分，我们肯定会尽量帮你们认的。但有些流程它不得不走，我们也没办法。

那一下我愣住了。我以为我面对的是一堵墙，结果对面站着的是一个也想帮我的普通人。

**第二件**，是临床的同学上组织胚胎课的时候，因为教学师资不足，华工请了中大的老师过来讲课。结果临床的同学发现——中大来的老师不愧是中大的，这 PPT 念得果然比华工快。

（是的，这条是拿来搞笑的。但笑完之后你会发现：一个学校承认自己某个方向师资不足，然后**去请外面的人来补**——这件事本身就很务实。）

所以务实不是在宣传册上写"求真务实"四个字。

**务实是：**

- 老师上课不念 PPT，而是直接讲这个模型在工厂里怎么用
- 社团不搞虚头巴脑的仪式，拉个群就开始干活
- 学长学姐愿意花两小时给你讲他们踩过的坑，而不是敷衍一句"加油"
- 你提一个方案，没人问你"这符合理论吗"，而是问"这跑得通吗"

**这一件件小事加起来，就是一个学校的精神。**

它是这个学校里师生的做事态度。

所以我们承认我们做不好，但这只是暂时的。

**我们永远相信着，我们能改。**
