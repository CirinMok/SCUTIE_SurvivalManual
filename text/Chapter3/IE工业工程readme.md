### 课程

* 在国内的大学中比较有意思，部分被分到管理学院，其余被分到机械学院。

其中机械学院有：清华大学、上海交通大学、重庆大学、浙江大学等；管理学院有：天津大学、西安交通大学等——当然，只是研究方向与侧重点不一致而已。



* 总的来说，我们的课程主要关注以下三类：

1. 管理与数学
   主要包括：**运筹学**、**管理统计学**、**数据库与数据系统**、**预测与决策方法**；
   管理学原理、管理信息系统、**生产计划与控制运营管理**、服务运作管理、质量管理、供应链管理、物流管理、库存管理
2. 仿真模拟与机械
   主要包括：系统仿真、人因工程学；基础工业工程、设施规划与物流系统、产品开发
3. 经济与技术
   主要包括：**微观经济学**、技术经济学

数学管理是理论根基，仿真模拟是使用的具体工具，经济与技术是考虑方向。但仅仅是考研来说的话，最重要的专业课程是大三上的运筹学与大三下的管理统计学。



* 除此之外，还需按照学院规定的课程额外选修专业课与通选课，修够特定的学分。

 如果想在考研与就业有竞争力的话，建议选学一两门涉及机器学习的数据分析课程，比如唐四慧老师的《商业数据分析》、沈子凡老师的《商业决策》、朱文斌老师的《大数据挖掘》。

### 就业

过往就业情况不一而足，20年以前大多入职互联网企业，但在20年之后大多入职新能源制造业。具体还是看各位兴趣方向与实力，好消息就是你投岗位绝对不会被筛简历啦。



### 最后的寄语

工业工程适合什么样的人？如果要我回答，我会说是有勇气为自己决策负责的人。以事后的角度来看，工业工程让一些人却步的比较重要的原因是，他看IE拿管理学学位就放弃了。



也确实是这样子，来到工业工程的人大多对自己未来有个想法，但在原专业的阻力太大，于是转到工业工程来。换句话说，工业工程适合自己已经有明确的目标规划的人，如果你是属于按部就班的完成任务，那传统工科确实可能比较适合你——按部就班完成工作，拿一个稳定的薪水，没什么不好。但来到工业工程，你要面对的是广泛的知识，许许多多需要重新学习的内容。



我认为工业工程更多的是给了你一个机会，一个成为你理想中自我的机会。在这里你可以尽情地成为你理想的自己，你可以在运筹学重新理解线性代数、在人因工程学会CAD、在数据分析学习数学建模······



没有人能阻止你成为你自己，我在原专业你可能有数不清的实验，学着没有意义的知识，过着枯燥的人生。但来到IE，周围的同学们都是不安分于平庸的人，你会重新锚定你的人生——你究竟想好要怎么过了吗？



如果决定了，那就去做吧！
