# B.6 数据相关谬误

- 数据来源不明
- 研究未被重复验证
- 适用范围过时
- 通过省略数据欺骗（只谈百分比，不谈规模）
- 数据结论 ≠ 需要证明的结论
- 平均值含糊（平均数 / 中位数 / 众数）
- 图表故意拉长缩小

# B.7 因果相关谬误

| 谬误 | 含义 |
|---|---|
| **过度简化因果** | 用不足以解释全局的单一因素解释事件 |
| **忽略共同原因** | 两件事相关，其实是第三个因素导致 |
| **事后归因** | 仅仅因为 B 在 A 之后发生，就认为 A 导致 B |
| **基本归因错误** | 解释他人行为时高估个人因素、低估环境因素 |

**寻找替代原因的标准：**

- 在预测类似事件上的成功率
- 有多少已接受的事实支持它
- 有多少已接受的信念不支持它
- 它能解释多少种不同类型的事实

---

# B.8 论证结构相关谬误

- **滑坡谬误**：假设 A 会引发一连串不可控后果，而实际上有现成程序可以阻止
- **循环论证**：用结论本身（换个措辞）作为理由
- **因果混淆**：把"解释已知现象"和"论证未知观点"搞混

---

# B.9 推理的两条路

| 类型 | 方向 | 特点 |
|---|---|---|
| **演绎** | 一般 → 特殊 | 前提为真则结论必真 |
| **归纳** | 特殊 → 一般 | 结论是概率性的 |
