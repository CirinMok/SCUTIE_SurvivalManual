# A.2 关键词设计

## 第一步：从目的倒推关键词

```
目的 → 领域背景 + 主体 + 行为 → 关键词框架
```

## 第二步：学会用搜索语法

| 语法 | 作用 | 示例 |
|---|---|---|
| `AND` / 空格 | 与 | `工业工程 就业` |
| `OR` | 或 | `供应链 OR 物流` |
| `-` | 非 | `IE -国际` |
| `"…"` | 精确短语 | `"生产计划与控制"` |
| `site:` | 限定站点 | `site:zhihu.com` |
| `filetype:` | 限定文件类型 | `filetype:pdf` |
| `intitle:` | 限定标题 | `intitle:运筹学` |
| `inurl:` | 限定网址 | `inurl:report` |

::: tip 提示
中文搜索用**半角**符号效果更好。
:::

## 第三步：换同义词

从第一步学到的术语出发，去找**衍生词、全称与缩写、中英文对照**。
