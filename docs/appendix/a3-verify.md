# A.3 找信息源

**通用入口：**

- **虫部落**系列（搜索、学术、电子书聚合）
- **AnywhereAnything**：跨站搜索导航
- **similarsites**：查找相似网站

**按平台类型：**

| 类型 | 平台 |
|---|---|
| 社区问答 | 知乎、Quora、贴吧、豆瓣 |
| 视频 | B 站、抖音、YouTube、快手 |
| 技术 | CSDN、GitHub、Stack Overflow |
| 财经 | 雪球、脉脉 |
| 消费 | 小红书、得物、什么值得买 |

**换三个维度再搜一次：语言 / 时间 / 关键词。**

# A.4 信息对比与验证

**批判性思维找证据：**

1. **线上原文 vs 线下访谈**——一手信息优先
2. **找最早出处**——`original`
3. **交叉验证**：同一件事，不同立场的人都怎么说？

**信源等级（从高到低）：**

```
期刊 > 学位论文 > 会议论文 > arXiv 预印本
官方文件 > 一手访谈 > 行业研报 > 二手转述
```

**常用权威源：**

- 国家哲学社会科学文献中心（ncpssd.org）
- 中国统计数据库（stats.gov.cn）
- Our World in Data
- 得到 / Open Library（书籍）
