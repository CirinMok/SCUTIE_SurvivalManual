# B.1-B.2 提问检视与论题

> 这一节教你**怎么不被忽悠**。
> 用处：看营销号、读研报、听讲座、甚至和同学辩论的时候。

## B.1 提问检视表

看任何一段论证，问三个层次的问题：

**一、是否浪费脑力？**

- 这个话题讨论的情景是什么？目的是什么？
- 对我来说重要吗？

**二、结构**

- 结论是什么？论题是什么？
- 前提和理由是什么？论证推理过程是什么？

**三、细节**

- 论题和结论是否对齐？
- 结论的倾向、局限是什么？有没有绝对化、二分？

---

## B.2 论题：事实 vs 价值

- **事实性论题**：世界**是**什么样
- **价值性论题**：世界**应该**怎么样

::: tip 提醒
**警惕"应该"思维的滥用。**

很多事情你无法控制，把"应该"改成"希望"，心态会好很多。
:::
