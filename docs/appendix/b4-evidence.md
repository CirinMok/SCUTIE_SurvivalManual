# B.4 选择谬误

- **二分法**：明明有多个选项，却假想只有两个
- **追求完美**：因为方案不能解决所有问题，就认为它完全不可取

**破除**：给结论加上限定条件——"在什么条件下，这个结论是成立的？"

---

# B.5 论据相关谬误

| 谬误 | 含义 |
|---|---|
| **以偏概全** | 用有限的样本得出整体结论 |
| **诉诸权威** | 引用权威，但该权威对此论题无专门知识 |
| **诉诸公众** | 因为很多人都这么说，就认为有道理 |

**论据来源类型**：典型案例、权威意见、个人经历、当事人证言——**各有局限，都要交叉验证**。

**调查问卷四查**：抽样能否代表整体？样本够大吗？覆盖够广吗？随机性够吗？
