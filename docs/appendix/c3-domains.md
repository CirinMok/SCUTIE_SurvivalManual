# C.3 与 IE 直接相关的知识域

## ① 运筹与优化（07 理学·数学）

```
运筹学
├─ 线性规划 → 单纯形法 → 对偶理论
├─ 整数规划
├─ 非线性规划
├─ 动态规划
├─ 图论与网络流
├─ 排队论        ← 与系统仿真直接对接
├─ 库存论        ← 与库存管理、供应链对接
├─ 决策分析      ← 与预测与决策方法对接
└─ 博弈论        ← 与微观经济学、管理学对接
```

**关联课程**：运筹学、预测与决策方法、系统仿真

## ② 统计与数据（07 理学·统计）

```
概率统计
├─ 概率论（测度论基础）
├─ 数理统计
├─ 回归分析 / 多元统计
├─ 时间序列分析
├─ 随机过程      ← 排队论的理论基础
├─ 贝叶斯统计
├─ 因果推断      ★ 数据分析岗的核心壁垒
└─ 生存分析（医学生存分析）
```

**关联课程**：管理统计学、商业数据分析、大数据挖掘

::: tip 给 IE 的提醒
**因果推断** 是被严重低估的一块。AB 实验、政策评估、定价策略背后的方法论都在这里。
:::

## ③ 计算与工具（08 工学·计算机）

```
计算机
├─ 编程语言（C / C++ / Python / Java）
├─ 数据结构与算法
├─ 操作系统
├─ 计算机网络
├─ 数据库原理      ← IE 必修
├─ 机器学习
│   ├─ 有监督学习
│   ├─ 无监督学习
│   └─ 强化学习
└─ 数字图像处理
```

**关联课程**：数据库、管理信息系统、大数据挖掘

> 对 IE 来说，**不需要学到 408 的深度**。但 `SQL + Python + 一门统计工具` 是通用货币。

## ④ 管理与运营（12 管理学）

```
管理
├─ 工商管理
│   ├─ 会计 / 财管 / 税法 / 审计
│   ├─ 战略管理
│   ├─ 人力资源管理
│   └─ 市场营销
├─ 管理科学与工程   ★ IE 的学科归属所在
├─ 公共管理（行政、医疗、教育、社保）
└─ 情报学（信息检索）
```

**关联课程**：管理学原理、生产计划与控制、质量管理、供应链管理、物流管理、库存管理

## ⑤ 经济与金融（02 经济学）

```
经济学
├─ 理论
│   ├─ 微观：供需、博弈论、国富论
│   ├─ 宏观：国际金融、货币银行学、财政学
│   └─ 计量经济学
└─ 应用
    ├─ 投资学、公司理财
    ├─ 估值模型（DCF）
    └─ 行业研究（投研、IPO）
```

**关联课程**：微观经济学、技术经济学
