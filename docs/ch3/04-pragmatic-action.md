# 3.4 务实的行动

## 从"想清楚"到"开始做"

很多人卡在第一步：想不清楚，所以不动。

但现实是：**你不可能在岸上想清楚怎么游泳。**

正确的顺序是：

```
做一个小动作 → 观察结果 → 调整 → 再做
```

而不是：

```
想清楚全部 → 完美执行 → 一次成功
```

**先做一个能做的版本，再迭代。**

- 不知道要不要学 Python？装个环境，跑通一行 `print("hello")`
- 不知道要不要考研？买本数学书，做两章题
- 不知道要不要走数据分析？打开一个公开数据集，用 Excel 画个图

**行动本身会给你答案，思考不会。**

## 关于「华工很务实」

进校之前，我经常听到别人评价华工，只有两个字：**务实**。

我当时很不理解。务实算什么评价？

后来我懂了。

务实不是一个宏大叙事，它是**一件件小事**。

- 是老师上课不念 PPT，而是直接讲这个模型在工厂里怎么用
- 是社团不搞虚头巴脑的仪式，拉个群就开始干活
- 是学长学姐愿意花两小时给你讲他们踩过的坑，而不是敷衍一句"加油"
- 是你提一个方案，没人问你"这符合理论吗"，而是问"这跑得通吗"

**这一件件小事加起来，就是一个学校的精神。**

它是这个学校里师生的做事态度。

所以我们承认我们做不好，但这只是暂时的。

**我们永远相信着，我们能改。**
