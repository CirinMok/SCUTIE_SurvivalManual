# 3.4 务实的行动

## 从"想清楚"到"开始做"

很多人卡在第一步：想不清楚，所以不动。

但现实是：**你不可能在岸上想清楚怎么游泳。**

正确的顺序是：

```
做一个小动作 → 观察结果 → 调整 → 再做
```

而不是：

```
想清楚全部 → 完美执行 → 一次成功
```

**先做一个能做的版本，再迭代。**

- 不知道要不要学 Python？装个环境，跑通一行 `print("hello")`
- 不知道要不要考研？买本数学书，做两章题
- 不知道要不要走数据分析？打开一个公开数据集，用 Excel 画个图

**行动本身会给你答案，思考不会。**

## 关于「华工很务实」

这句话在 1.6 已经专门讲过，这里不重复，只补上它的下半句：

**务实不是"已经做好了"的证明，而是"现在做不好，但我们还会改"的姿态。**

所以我们承认很多东西我们现在还做不好——但这只是暂时的。

**我们永远相信着，我们能改。**
