# 1.5 自我：以终为始

史蒂芬·柯维说的"以终为始"，翻译成大学生能听懂的话就是：

**先想清楚四年后你想站在哪里，再倒推今天该干什么。**

大部分人做选择的方式是"别人都在考，我也考"、"这个看起来比较稳"。结果就是四年后站在毕业季的岔路口，手里握着三个都不太想要的选项。

正确的做法是反过来：

## 第一步：定终点

你想要的是哪一种生活？

| 方向 | 关键词 | 代价 |
|---|---|---|
| 升学（考研/保研） | 学历提升、延缓就业、换赛道 | 一年高压备考，机会成本高 |
| 就业 | 早入场、攒经验、拿现金 | 起点学历可能受限 |
| 考公 / 选调 | 稳定、体制内、地域绑定 | 竞争激烈、收入天花板明确 |

注意：**这三条路不是互斥的，但不能同时全力准备。** 你必须在某个时间点做出取舍。

## 第二步：查信息

选方向之前，先把信息补齐。第二、三章会展开讲，这里只列清单：

- **升学**：考研考什么专业、报录比多少、专业课考哪几门；保研比例、绩点线、加分项
- **就业**：目标行业头部公司在招什么人、要求什么技能、什么时间开秋招/春招
- **体制内**：广东省人社厅、国家人社部、定向选调的政策文件原文（不是营销号解读）

## 第三步：倒排时间线

举个粗糙的例子：

```
目标：大四秋招进制造业/互联网做供应链或数据分析
├─ 大三上：运筹学、管理统计学拿到高绩点（专业课是硬通货）
├─ 大三下：找一个暑期实习（哪怕是中小公司，先有经历）
├─ 大三暑假：正式暑期实习，争取转正或拿到背书
├─ 大四上：秋招，投递 30+ 家
└─ 贯穿全程：学 SQL / Python / 数据分析工具，这是 IE 的通用货币
```

有了这张表，你每天该干什么就清晰了。**焦虑的反面不是躺平，是具体的行动。**
