# 1.1 IE 是什么：入门必读

> 在进入 IE 之前，先搞清楚自己站在哪里。

## 先欢迎一下

首先，欢迎来到工业工程 IE 的大家庭！

你可能因为各种各样的原因脱离了原来的专业，对新的专业抱着新的期待。所以下面这篇文档，可以给你大概交流一下**老登の经验**。

大二通过 2+2 二次选拔、大三正式转入 IE，等于把前两年在原专业的积累暂时放到一边——这需要莫大的勇气。IE 希望你能保持这股心气，多去提问、多去尝试，给大学剩下的两年交出一份满意的答卷。

## 那么，IE 到底是什么

> **IE 是一门以系统为对象，综合运用数学、工程与管理方法，对人机料法环等进行设计与优化，以提升效率（库存周转）、订单完单率（OTIF）和效益（成本费用）的交叉工程学科。**

说得再直白一点：别人关心"这个东西能不能造出来"，IE 关心"这个东西怎么造得又便宜又快又好又不容易出错"。

在 2026 年刚刚交棒的苹果 CEO [库克](https://www.bilibili.com/video/BV1G7tG6tEwL)，所学专业便是工业工程（IE, Industrial Engineering）

如果说乔布斯是设计研发苹果核心产品的人，那工业工程出身的库克就是让苹果规模化生产流通供应全球的人。


## 华南理工 工业工程适合什么样的人

如果要我回答，我会说：**是有勇气为自己决策负责的人。**

从结果看，工业工程让一些人却步的一个重要原因，是他看到 IE 拿的是管理学学位，就放弃了。

也确实是这样。来到工业工程的人，大多对自己的未来有个想法，只是在原专业的阻力太大，于是转到 IE 来。

换句话说：

- **如果你已经有明确的目标规划，工业工程会放大你的优势。** 但这不是准入门槛——更常见的情况是：你还没想清楚要什么，只是不愿意继续待在一个自己不认同的位置上。
- 如果你属于"按部就班完成任务"型，那传统工科可能确实更适合你——按部就班完成工作，拿一份稳定的薪水，没什么不好。
- 但来到工业工程，你要面对的是**广泛的知识**，和许许多多需要重新学习的内容。

所以，**"目标明确"这件事，不必赶在转专业之前完成**。它更像是在一次次和现实碰撞之后长出来的东西——你先迈出一步，现实给你反馈，你再调整方向。你要的从来不是一个现成的答案，而是一个**允许你试错的位置**。

## 但也正因如此

我认为工业工程更多的是给了你**一个机会**：一个成为你理想中自我的机会。

在这里你可以尽情地成为你理想的自己：

- 你可以在**运筹学**里重新理解线性代数
- 可以在**人因工程**里学会 CAD
- 可以在**数据分析**里学习数学建模
- 可以在**系统仿真**里用代码复现整个工厂的运作

在原专业，你可能有数不清的实验，学着没有意义的知识，过着枯燥的人生。但来到 IE，周围的同学们都是**不安分于平庸的人**——你会重新认识自己该往哪走。

至于"我究竟想好要怎么过了吗"，这不是一句话能回答的。这本书后面的章节，会陪你一起想。
