# 2.3 实习

**基本方向**：

- **互联网**：数据分析、商业分析、产品、运营、供应链
- **制造业**：工业工程师、生产计划、精益改善、供应链、质量
- **咨询**：运营咨询、供应链咨询
- **物流**：顺丰、京东物流、菜鸟等

**什么时候开始**：大二暑假就可以开始尝试了。第一份实习不要挑，中小公司也去，目的是"有经历"和"知道职场什么样"。

**怎么找**：

- 学长学姐内推（最高效，也最需要平时的关系积累）
- 各公司官网 / 招聘公众号
- 实习僧、牛客等平台
- 学院的实习信息群

一般来说，线下真人1v1的渠道会好过线上海投。
