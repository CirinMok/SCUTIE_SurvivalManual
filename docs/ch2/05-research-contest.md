# 2.5 科研与竞赛

## 数学建模

**性价比最高的竞赛之一。**

- 组队建议：找一个会写代码的、一个会建模的、一个会写论文的
- IE 的运筹学、统计学基础，在数模里非常吃香
- 获奖对保研加分、简历都是实打实的帮助

## 大创（大学生创新创业训练计划）

和同学一起组队参加，**谁不想自己的简历好看呢**（哈哈哈）。

## 亮剑 IE

学院/专业相关的品牌活动，建议关注并参与。

## 实验室安全流程搭建

如果你进实验室，安全流程的搭建和遵守是硬性要求。别嫌麻烦——**这是保护你自己，也是 IE 的本行**（流程标准化嘛）。
